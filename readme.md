# 🍳 Sizzle & Share - Interactive Food Recipe Challenge Platform

## Project Overview
Sizzle & Share is an interactive web platform where food enthusiasts can:
- Discover recipes based on ingredients they have at home
- Cook delicious dishes using suggested recipes
- Share their creations by uploading photos
- Participate in weekly challenges and compete on leaderboards
- Connect with other food lovers through likes and gallery

## Installation

### Requirements
- XAMPP/WAMP/MAMP (PHP 7.4+)
- MySQL 5.7+

### Setup Steps
1. Copy the `sizzle-and-share` folder to `htdocs` (XAMPP) or `www` (WAMP)
2. Start Apache and MySQL services
3. Create database: `CREATE DATABASE sizzle_share;`
4. Import database schema from `sql/database.sql`
5. Update database credentials in `php/config/database.php`
6. Access the website at `http://localhost/sizzle-and-share/`
